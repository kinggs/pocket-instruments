# Security

## Reporting a vulnerability

Report it privately. On the repository, open the **Security** tab and choose
**Report a vulnerability**. Do not open a public issue for it.

Say what you did, what happened, and which host it was on (the VCV Rack plugin or the web
page). A file that reproduces it helps most.

## What counts here

- A crash or memory fault from a crafted snapshot or Rack patch.
- Anything in the web page that runs another person's code.

A wrong sound, a failed build or a broken layout is a bug, not a vulnerability. Use the bug
form for those.

## What to expect

- One person maintains this project in spare time. A reply may be slow.
- There is no bounty.
- A fix is credited to the reporter, if the reporter wishes.
- Only the latest `main` is supported. There are no maintained older versions.
