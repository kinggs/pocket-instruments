# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Its full text applies here. Read it at that link.

## Our pledge, in short

- Be kind. Assume the other person means well.
- Argue about the work, never about the person.
- No harassment, no insults, no sexual attention, no publishing of anyone's private details.
- Everyone is welcome, whatever their background, identity or level of experience.

This holds in issues, pull requests, reviews and anywhere else the project is represented.

## Reporting

If something is wrong, report it with GitHub's own report tools: the `...` menu on the
comment, issue or pull request, then **Report content**.

⚠ There is no private contact address for this project yet.

One person maintains this project, so a reply may take a while. Reports are kept private.
The maintainer may edit or remove comments, commits and issues that break this code, and may
block a person who keeps breaking it.
